## 한국어·영어·중국어·베트남어 문제은행 교차검증
네 언어의 문제은행은 문항 번호가 1:1로 대응되도록 만들어져 있어서(같은 문제의 번역), 전체 1,800문항의 정답을 서로 대조하는 자동 검증을 각 언어마다 했습니다.
- 영어 대조 시 최초 1건의 불일치가 발견되어 원인을 확인한 결과 한국어 원본 PDF에 "정답：1. 3" 처럼 쉼표 대신 마침표로 복수정답을 표기한 예외 케이스가 있었고, 이를 정확히 반영하도록 파싱 로직을 수정해 한국어·영어 정답이 100% 일치하게 되었습니다. 영어 문제은행에서 정답 표기 자체가 누락된 문항 1건(이륜자동차 689번)은 한국어판의 정답으로 채워 넣었습니다.
- 이후 이 수정을 반영한 상태로 베트남어 문제은행을 대조한 결과 1,800문항 전체가 처음부터 100% 일치했습니다 (별도 수정 불필요).
- 중국어 문제은행은 두 가지 추출 오류가 있었습니다: (1) 일부 페이지에서 PDF 텍스트 추출 순서가 뒤바뀌어(예: 169번 문항 전체가 168번보다 앞에 추출됨) 문항 번호를 순서대로 기대하던 기존 로직이 깨졌고, (2) 1·2종 문제은행 455번 문항은 원본 PDF에 번호 뒤 마침표가 누락되어("455 하략..." 처럼 마침표 없이) 문항 인식 자체가 안 되는 경우가 있었습니다. 두 문제 모두 "■ 정답표시(■ 正确答案)" 마커를 기준으로 각 문항을 역으로 매칭하고, 누락된 번호는 1~1000 중 빠진 번호로 자동 추론하도록 파싱 로직을 개선해 해결했습니다. 개선 후 1,800문항 전체가 한국어판과 100% 일치했습니다.
